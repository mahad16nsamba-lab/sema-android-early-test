# Sema Android - early test only

> **This is an unfinished test candidate, not a finished app or production release.**
>
> **Important safety warnings**
> - Sign-ups connect to a real Firebase project. Do not use a password you use elsewhere.
> - The app has not been tested on a phone.
> - Chat security is unverified. **Do not use chat or share sensitive/personal content.**
> - This app is **not end-to-end encrypted**.
> - The APK is test-signed, not signed for a production release.
> - Room creation is not implemented.

This repository contains only this notice and the candidate APK attached to the GitHub early-test prerelease. No app source code, backend changes, or private project files are published here.

## Download

See the [early-test prerelease](https://github.com/mahad16nsamba-lab/sema-android-early-test/releases/tag/early-test-2026-11-27) and download `Sema-Green-Firebase-Candidate-TEST.apk`.

## Install

1. Download the APK from the prerelease on an Android device.
2. Open the downloaded APK and follow the Android prompt to allow installation from that source, if asked.
3. Install only if you understand the warnings above. To remove it, uninstall Sema from Android settings.

## What this is

A public early-test distribution of the dark-green native candidate, shared to gather limited testing feedback. It is not represented as complete, secure, or ready for sensitive conversations.
